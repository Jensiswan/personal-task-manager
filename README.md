# Personal Task Manager

A simple web-based Personal Task Manager developed using Laravel and MySQL. The system allows users to create, manage, update, and organize their personal tasks.

## Features

### 1. Add Task

Users can create a new task by providing the task name, description, status, priority, and due date. The information is then saved to the MySQL database.

### 2. View Tasks

Users can view all saved tasks from the dashboard. Each task displays important information such as the task name, status, priority, and due date.
